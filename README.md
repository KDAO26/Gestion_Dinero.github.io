# Mi Dinero — versión 1

Página web personal para controlar una cuenta de débito y organizar gastos por quincena.

## Incluye
- Saldo disponible y dinero inicial.
- Contador de transporte: cada pasaje suma automáticamente el precio configurado (por defecto $3.500).
- Contador de almuerzos: cada almuerzo suma automáticamente el precio configurado (por defecto $20.000).
- Gastos variables mediante formulario.
- Ahorro separado de los gastos.
- Meta de ahorro y barra de progreso.
- Reporte de la quincena actual en tabla.
- Cierre automático de quincena: 1–15 y 16–fin de mes.
- Historial de quincenas cerradas.
- Configuración de precios y meta.
- Datos guardados en localStorage del navegador.
- Diseño responsive para computador y celular.

## Cómo usar
1. Abre `index.html` en un navegador.
2. En Configuración coloca tu dinero inicial y ajusta los valores si lo necesitas.
3. Usa `+` en Transporte y Almuerzos para registrar consumos.
4. Usa "Registrar gasto" para otros gastos.
5. Usa "Añadir ahorro" para separar dinero para una meta.

No se solicitan datos bancarios, número de tarjeta, CVV, claves ni credenciales de Nu.

## Nota
Esta versión funciona localmente en el navegador. No está conectada al banco Nu ni sincroniza movimientos bancarios automáticamente.
